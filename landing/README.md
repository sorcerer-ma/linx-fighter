# 落地页（landing）

给「共鸣：闻声对决」做的产品落地介绍页，单页静态站点，面向技术型评委。视觉与文案跟随产品介绍视频的风格（米白 + 淡绿 + 橙），结论与数字以仓库文档和真机实录为准。

## 在线体验

<http://111.62.156.213:10659/landing/>

部署在演示服务器的 nginx 静态路径 `/landing/` 下。演示机的对外 80 端口没有映射，所以地址带 `:10659`；页面里引用的视频、字体与 vendor 脚本都随页面一起上传，打开即可完整播放，不依赖 CDN。

## 本地预览

```bash
cd landing
python3 -m http.server 8151 --bind 127.0.0.1
# 打开 http://127.0.0.1:8151/
```

不需要构建步骤：`index.html` + `styles.css` + `main.js` 三个文件即页面本体，`vendor/` 里是本地化的 GSAP 3.12.5、ScrollTrigger、Lenis。

## 目录

| 路径 | 说明 |
| --- | --- |
| `index.html` | 页面结构与全部文案 |
| `styles.css` | 设计令牌、组件样式、响应式（断点 880px / 1080px） |
| `main.js` | GSAP + ScrollTrigger 动效、玩法定格叙事、表情切换、翻面、平滑滚动与逐屏吸附、养成升级动画 |
| `assets/faces/` | 8 个表情（496×496，按屏幕比例裁好）；`_raw/` 是裁切前原图，留作重裁 |
| `assets/fonts/ZiHunBianTaoTi.woff2` | 标题字体子集（84 KB，从系统字体 2.1 MB 抽子集；改文案后需重抽，缺字会回退成系统字体） |
| `assets/poster-*.jpg` | 三段视频的封面帧 |
| `assets/logo.png` | 导航与 favicon 图标（128×128） |
| `assets/icons/nfc.svg` | NFC 字形原文件：来源 Simple Icons（CC0），页内已内联成 sprite 的 `#i-nfc`，可直接 `currentColor` 着色 |
| `media/` | 视频，见下 |
| `vendor/` | 本地化的动画库，避免线上依赖 CDN |

> 标题字体是子集，改完 `index.html` / `main.js` 的中文文案要重抽一次，否则新增的字会回退成系统字体。抽子集的做法：把页面可见文本与 `main.js` 里的中文合起来去重，再
> `pyftsubset ZiHunBianTaoTi-2.ttf --text-file=<字符文件> --flavor=woff2 --output-file=assets/fonts/ZiHunBianTaoTi.woff2`，
> 最后核对 `cmap` 里没有缺字。

## 视频

| 文件 | 用途 | 规格 |
| --- | --- | --- |
| `media/intro.mp4` | 首屏产品片 | 60 秒，1280×720，5.1 MB |
| `media/faces-full.mp4` | 表情实录（完整版） | 3 分 25 秒，1280×720，4.1 MB |
| `media/pvp.mp4` | 设备语音对话实录 | 3 分 06 秒，1280×720，7.8 MB |
| `media/pvp-battle.mp4` | 双人对战实录 | 5 分 08 秒，1280×720，12.9 MB |

全部转成 H.264 + `+faststart`，统一用浏览器原生控件播放完整版，不再有节选片与自定义弹窗；视频一律 `preload="metadata"`，只有浏览器需要时才真正拉流。

**视频随仓库保留**（`media/*.mp4`），根 `README.md` 直接链接这四个文件；部署时仍要和页面一起上传，否则别人打开页面看到的只有封面：

```bash
rsync -av --exclude '.DS_Store' landing/ user@host:/path/to/static/landing/
```

## 口径与边界

- 「实录」字样只用在有真实影像的位置；产品概念动画单独标注为视觉化表达。
- 页面里的表情是手写 SVG（照着真机表情还原），只用来示意状态切换；实际效果以 `media/faces-full.mp4` 为准。
- 04「结构」与 08「养成」、09「商业」三屏标注「设想与推演 · 尚未交付」，不写成已交付功能；玩法与真机实录按现有实现陈述。
- 对局数字（先手 14 / 后手 18、能量与伤害、第 3 轮起 +2）与 `docs/game/game-design.md` 一致；92.2% 是自拟 64 条语料上的端到端命中率，不是 ASR 字准率。
- 真机唤醒、ASR 与 TTS 仍在验收中，页面不声称「已验收」。

## 无障碍与降级

- 系统开启「减少动态效果」时关闭平滑滚动、逐屏吸附与逐格动画，表情停在静止状态。
- 没有 GSAP 时所有内容依旧可读（初始隐藏只在 JS 里设置）。
- 导航提供跳到各屏的锚点；视频都带 `aria-label`，统一用浏览器原生控件。
