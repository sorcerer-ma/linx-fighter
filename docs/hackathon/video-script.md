# 90 秒先导片脚本

给评委和投资人看的开场片，也当现场演示的兜底素材（设备掉线时直接播它）。

- 目标时长：110 秒（可剪到 90 秒，删减点见文末）
- 画幅：16:9，1920×1080，24fps
- 语气：不喊口号、不用「颠覆/赋能/元宇宙」；让画面和原话说话
- 声音：现场同期声优先，口播单独录一遍贴进去；全程有轻微环境声，不要静音感

屏幕上出现的每一句播报，都必须是玩家真的说出来、伙伴真的答出来的原话——**不设计假台词**。

## 拍摄清单

**必须有的镜头**

1. 开场双人对坐全景（机位 A，35mm 等效，f/2.8，浅景深，桌面留白）；
2. 设备灯效与转向特写（机位 B，微距，1–2 秒一个）；
3. 手部特写：全程不触屏，只放在桌上或拿起杯子（回应「手是空的」）；
4. 真实对局完整一手（出招 → 播报 → 应对 → 结算），至少 3 条可用素材；
5. 一次「说错了」的重说：玩家含糊说完，伙伴答「没听出来」，玩家重说一遍——这条比成功镜头更有说服力；
6. 收尾碰设备（不要设计成广告式击掌）。

**屏录清单**

- `pnpm validate` 完整跑一遍（数字能对上 256,000）；
- 手机伙伴页：生命值、能量、大招徽记的三种状态各 3 秒（素材由移动端同学提供，未就绪则用沙箱页代替并在片尾注明）；
- `/admin` 看板与 `/events` 流（可选，1–2 秒即可）。

**收音**

- 玩家领夹麦 + 设备近场麦，两条轨分开录，后期以设备播报为主、玩家原话为辅；
- 口播单独录，语速偏慢，句间留 0.3 秒，方便卡点。

**不拍**

- 不拍任何后台配置、密钥、控制台证书页；
- 不用第三方品牌 logo 做对比镜头；
- 不摆拍「AI 思考中」的界面；
- 不承诺未验证的真机效果（唤醒率、朗读延迟）。

## 字幕与图形规范

- 字体：PingFang SC，屏幕字 Medium，关键词 Semibold；
- 屏幕字一行不超过 14 字，最多两行；位置统一在画面下三分之一；
- 颜色只用三色：纸白 `#F7F4EF`、墨 `#15171B`、朱红 `#D9503B`；关键词用朱红，其余用墨；
- 播报字幕加「」并在右下角标一句「伙伴原话」；不加重影、不加发光；
- 转场只用硬切和 4 帧黑场，不用叠化、不用 zoom blur。

## 90 秒压缩版怎么删

1. 镜头 2 压到 6 秒（三个画面各 2 秒）；
2. 镜头 6 架构动画只留 6 秒，去掉模型层解说；
3. 镜头 7 只保留 256,000 一个数字；
4. 镜头 8 只留「无热词 → 端侧同音」一条；
5. 收尾口播压成一句：「它只是两个人的游戏。」

## 成片验收

- 时长 90–120 秒；
- 每一句字幕都能在录屏或同期声里找到出处；
- 不出现未验证的数字和效果；
- 关掉声音也能看懂发生了什么（这是评委在嘈杂现场看的版本）。

## 待人工确认

- 出镜玩家的授权、场地与拍摄时间；

- 是否需要在片尾加团队署名与联系方式。
