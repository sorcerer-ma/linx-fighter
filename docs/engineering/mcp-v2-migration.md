# MCP v2 实施与验收

## 状态与范围

本文记录当前 v2 实现与切换边界。平台提示词须手动配套更新，代码合并不代表部署或平台验收完成。

公开工具仅 game_say 和 wait_event，content 文本块为单个 v:2 JSON，不输出 structuredContent。内部 service 保留 text/presentation 供既有规则测试和安全退路使用。规则数值、随机顺序、身份与事务归属不变。

## 模块职责

| 模块 | 实现与边界 |
| --- | --- |
| 游戏事实 | 从 Battle、BattleEvent 和真实拒绝分支生成状态、事件、合法选择与能量缺口，不解析播报反推事实 |
| MCP | Unicode 1～200 字原话，只执行一次；超长拒绝不截断；两工具、紧凑 JSON、故障 unknown |
| Agent | 从事实自由表达；不使用完整候选白名单或原播报数字集合；silent／unknown 不强行生成，失败用 say/text，不重做游戏 |
| 校验 | 保留数值、归属、先手、胜负、待结算与明确阶段矛盾检查；邀请措辞不强制固定词。validationReason 仅固定码，不记录模型候选或用户全文 |
| 等待与补账 | 30 秒有界等待，取消不推进游戏；按身份和局号一次消费事实，换局不播旧局结果，包含终局事件 |
| 页面／脚本 | 最终 reply 才显示与播放；SSE state只更新视觉，push不直接播报。播放完成后按 need 每条指令最多等待一次，取消／失败／超时不误触发等待 |
| ASR／TTS | 识别 final 输入与最终话术／播放完成／取消是接口边界；语音适配不解析 MCP、不重做游戏。独立云语音成果未自动混入本分支 |

## 具体边界

- 直接切换公开协议，不新增 MCP_PROTOCOL 配置或多协议自动猜测。内部兼容方法不代表公开保留旧五工具。
- 满能量蓄力映射 wrong_stage，并给真实 choices；不新增动作或改变消耗。
- 明确拒绝才能说未执行；工具异常或执行结果不确定返回 unknown。无可靠快照时给最小 unknown，不伪造资源，不鼓励自动重试。
- 单个 JSON 文本块上限为 **16 KiB UTF-8**。精确上限、超一字节、多字节和多事件压力夹具测试覆盖；超限不截断事实、不当作成功，返回有界 unknown，后续核实局面而非重做行动。此为项目上限，灵矽平台容量尚未证实。
- wait_event 默认最多 30 秒。等待、查询与后续行动共享事实消费；取消不消费未交付事件，重复等待不能重复交付同一战果。过期、换房、离开和换局清理旧事实。
- 快照 battleId 与 MCP 私有 `_meta["linx/battleId"]` 关联本次执行局面，不是身份参数或模型自编事实。未知故障不能用虚假的 null 局号吞掉核实提示。
- 一到两句、60 字是常规表达目标，不能为此省略必需战果；也不强制逐项念完背景资源。有限自然语言检查不保证所有语义正确，仍需人审与真实场景验收。

## 验证与切换

完整门禁包括类型检查、测试／覆盖率、数值对拍和构建。另验证：两种 MCP 传输、原话边界、silent、failed/unknown、不重复操作、镜像、双人交错、取消／超时／换局、终局单次补账、模型失败安全退路，以及页面实际播放顺序。隔离实例自对弈与浏览器验证不使用用户已有对局。

真实模型配置通过 Node --env-file 直接加载原项目已忽略配置，不读取输出或复制密钥，不改 .env。必须分别报告 JEV 路由／对手、MCP Chat、伙伴表达是否真实调用成功，启用不等于成功；不得用 mock 或本地 AI 回退宣称真实模型成功。

平台声纹、speaker 自动填充、回灌隔离、挂起前能否播完、真实 ASR／情绪音色与手机体验仍需专门验收。仓库提示词不会自动同步灵矽控制台。

### 说话人与页面提醒边界

`game_say` 与 `wait_event` 只接受本次平台声纹元数据。参数和姓名请求头不一致时静默拒绝，不沿用旧身份；白名单与对局席位校验独立于音色profile。等待服务端最多30秒、客户端留35秒，取消静默且不消费事实。

手机页面保留七类主动提醒：对手出招、对手接受挑战、大招资源就绪、主动／响应空闲、等待对手、等待接受挑战。SSE push是带身份／对局／一次性ID的信号，不是直接可播台词；沙箱向固定游戏服务取得当下事实，再交真实Agent表达与统一播放队列。入房／出招与wait_event消费去重，旧局、失效或取消信号不播，不重做游戏动作。忙碌、真实说话、输入或隐藏时让路；语音效果仍需平台与真人试听验收。

双人明确退出现在使用 end 的可选 cause=forfeit；win 仍按请求者视角镜像，旧 end 向后兼容。一人等待退出不产生胜负，已结束结果不反转。表达与解码需识别可选原因，只有该原因允许“逃跑”说法；取消等待、断网或关闭页面不等于退出。
