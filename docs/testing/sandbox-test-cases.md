# 沙箱对局案例（3 局，真实录制）

维护说明：最初统一为生命值与能量术语；后续播报改为伙伴第一人称（`我` / `对手`）并在战况里补上大招剩余次数，本文的播报原文保留录制时的说法，数值、判定与事件不变，不代表重新执行验证或重新录制。

口令说明：本文三局录制于旧口令时期，玩家说的「开房间」和播报里的「加入房间1234」都是当时的原话。现行入口已改为「共鸣对决，发起挑战」与「接受挑战，编号1234」，旧说法仍兼容，但不再作为引导文案；下文对局记录与播报原文按录制时保留，不改写。

本文件是沙箱跑出来的真实对局记录，不是手写样例：房间号、生命值、能量、播报文字全部来自服务端返回，只做了排版。

- 生成环境：游戏服务 `pnpm dev`（0.0.0.0:8000）+ 沙箱 `pnpm sandbox`（8100）
- 生成命令：`pnpm sandbox:selfplay --rounds 6 --json`（这次共跑 6 局，下面是从中挑出的 3 局典型）
- 链路：脚本 → `POST /api/say` → 沙箱 MCP 客户端 → `game_say` → 服务端判断与结算 → 播报原文返回
- 身份：A = 房主（开房间的人），B = 加入者（说「加入房间XXXX」的人）

## 规则速览（读案例时对照）

| 项目 | 数值 |
| --- | --- |
| 先手补偿 | 先手 14/14 生命值，后手 18/18 生命值 |
| 能量 | 初始 3，上限 5，主动出招那一步开始回 2 |
| 普攻 / 强攻 / 大招 | 1点能量 3 伤 / 2点能量 5 伤 / 4点能量 9 伤，大招每局 1 次 |
| 格挡 / 闪避 / 承受 | 1点能量减 2 伤 / 1点能量按概率完全闪开 / 0点能量但吃满伤害 |
| 伤害加成 | 第 3 轮起每轮 +2 |
| 暴击 | 命中后按概率 +2 伤 |

约定：播报里的「你」是收到这句话的玩家；以「刚才那一手。」开头的是服务端补账——把上一位玩家动作的结果补播给当时不在场的玩家，一条只补一次。

## 案例一 · 房间 9581（B 先手，A 胜）

**开局快照**：B（先手）14/14、能量 3；A（后手）18/18、能量 3；双方各 1 次大招。

**进入对局**

- **A 说**「开房间」→ **A 听到**「房间9581已开好，把房间号告诉另一位玩家，说「加入房间9581」就能进来。等对手进来再开打。」
- **B 说**「加入房间9581」→ **B 听到**「你进了房间9581，对面是另一位玩家。对决开始，你先手，你14点生命值，他18点生命值。」
- **A 说**「战况如何」→ **A 听到**「第1轮，你生命值18/18、能量3；对手生命值14/14、能量3。等对手出招。」

### 第 1 轮

- **B 说**「公鸡」（语音误识别，B 本来想说什么不重要，服务端按发音认成普攻）→ **B 听到**「你一记普攻已出手，等对手应对。」
  - 局面：B 14/14，能量 3→2；锁定 B 的普攻（3 点伤害），等 A 应对。
- **A 说**「格挡」→ **A 听到**「对手一记普攻，你格挡，掉1点生命值，剩17，轮到你出招。」
  - 局面：A 18→17，能量 3→2；B 14/14，能量 2。B 的普攻到此结算完。
- **A 说**「强攻」→ **A 听到**「你一记强攻已出手，等对手应对。」
  - 局面：A 17/18，能量 2→0；锁定 A 的强攻（5 点伤害），等 B 应对。
- **B 说**「承受」→ **B 听到**「刚才那一手。你一记普攻，对手格挡，掉1点生命值，剩17。对手一记强攻，你硬扛，掉5点，剩9，轮到你出招。」
  - 局面：B 14→9，能量 2→4；第 2 轮开始，轮到 B 出招。
  - 注意第一句是补账：B 上一手普攻的结果，B 当时正在等 A 应对，没听到。

### 第 2 轮

- **B 说**「大招」→ **B 听到**「你一记大招，对手能量耗尽只能硬扛，掉9点，剩8，等对手出招。」
  - 局面：A 17→8；B 9/14，能量 4→0，大招用掉；轮到 A 出招。
- **A 说**「强攻」→ **A 听到**「刚才那一手。你一记强攻，对手硬扛，掉5点，剩9。对手一记大招，你能量耗尽只能硬扛，掉9点，剩8。你一记强攻，对手能量耗尽只能硬扛，掉5点，剩4。第三轮开始，攻击伤害每轮加2，等对手出招。」
  - 局面：B 9→4，能量 4→0；A 8/18，能量 0；第 3 轮开始，轮到 B 出招。
  - A 一口气补到两件旧事：自己上一手强攻的结算、B 的大招结果。

### 第 3 轮

- **B 说**「强攻」→ **B 听到**「刚才那一手。对手一记强攻，你能量耗尽只能硬扛，掉5点，剩4。你一记强攻，对手能量耗尽只能硬扛，掉7点，剩1，等对手出招。」
  - 局面：A 8→1；B 4/14，能量 2→0（第 3 轮 +2 加成让强攻打出 7 点）。
- **A 说**「强攻」→ **A 听到**「刚才那一手。对手一记强攻，你能量耗尽只能硬扛，掉7点，剩1。你一记强攻，对手能量耗尽只能硬扛，掉7点，剩0。你击倒了对手，赢了这一局。」
  - 终局：A 1/18 胜，B 0/14 负；共 3 轮。

**复盘**：B 一上来用误识别的普攻抢先手，但 A 用格挡把 3 点压到 1 点；B 的大招把 A 打到 8 点，却被 A 连续两记强攻（第 3 轮起每记 7 点）反超。后手 18 点生命值的补正在这一局体现得很明显。

## 案例二 · 房间 4387（A 先手，B 胜）

**开局快照**：A（先手）14/14、能量 3；B（后手）18/18、能量 3；双方各 1 次大招。

**进入对局**

- **A 说**「开房间」→ **A 听到**「房间4387已开好，把房间号告诉另一位玩家，说「加入房间4387」就能进来。等对手进来再开打。」
- **B 说**「加入房间4387」→ **B 听到**「你进了房间4387，对面是另一位玩家。对决开始，对手先手，你18点生命值，他14点生命值。」
- **A 说**「战况如何」→ **A 听到**「第1轮，你生命值14/14、能量3；对手生命值18/18、能量3。轮到你出招。」
- **B 说**「公鸡」（此时没轮到 B）→ **B 听到**「现在还没轮到你出招，等对手先动。」
  - 这句没有推进回合：认出了招式，但当前不是 B 的动作时机，服务端只提示不结算。

### 第 1 轮

- **A 说**「强攻」→ **A 听到**「你一记强攻已出手，等对手应对。」
  - 局面：A 14/14，能量 3→1；锁定 A 的强攻（5 点伤害），等 B 应对。
- **B 说**「闪避」→ **B 听到**「对手一记强攻，你闪开了，轮到你出招。」
  - 局面：B 18/18 不损失生命值，能量 3→2；闪避成功，轮到 B 出招。
- **B 说**「强攻」→ **B 听到**「你一记强攻已出手，等对手应对。」
  - 局面：B 18/18，能量 2→0；锁定 B 的强攻（5 点），等 A 应对。
- **A 说**「格挡」→ **A 听到**「刚才那一手。你一记强攻，对手闪开了。对手一记强攻，你格挡，掉3点生命值，剩11，轮到你出招。」
  - 局面：A 14→11，能量 1→2；第 2 轮开始，轮到 A 出招。

### 第 2 轮

- **A 说**「强攻」→ **A 听到**「你一记强攻，对手能量耗尽只能硬扛，掉5点，剩13，等对手出招。」
  - 局面：B 18→13；A 11/14，能量 2→0；轮到 B 出招（B 能量 0，只能硬扛）。
- **B 说**「强攻」→ **B 听到**「刚才那一手。你一记强攻，对手格挡，掉3点生命值，剩11。对手一记强攻，你能量耗尽只能硬扛，掉5点，剩13。你一记强攻，对手能量耗尽只能硬扛，掉5点，剩6。第三轮开始，攻击伤害每轮加2，等对手出招。」
  - 局面：A 11→6；B 13/18，能量 0；第 3 轮开始，轮到 A 出招。

### 第 3 轮

- **A 说**「强攻」→ **A 听到**「刚才那一手。对手一记强攻，你能量耗尽只能硬扛，掉5点，剩6。你一记强攻，对手能量耗尽只能硬扛，掉7点，剩6，等对手出招。」
  - 局面：B 13→6；A 6/14，能量 2→0。
- **B 说**「强攻」→ **B 听到**「刚才那一手。对手一记强攻，你能量耗尽只能硬扛，掉7点，剩6。你一记强攻，暴击，对手能量耗尽只能硬扛，掉9点，剩0。你击倒了对手，赢了这一局。」
  - 终局：B 6/18 胜，A 0/14 负；共 3 轮。

**复盘**：B 用一次闪避白吃了一记强攻，随后双方都进入「能量打空只能硬扛」的交换；最后一手 B 吃到暴击加成（5+2+2=9），把 A 从 6 点直接清空。

## 案例三 · 房间 3068（B 先手，B 胜）

**开局快照**：B（先手）14/14、能量 3；A（后手）18/18、能量 3；双方各 1 次大招。

**进入对局**

- **A 说**「开房间」→ **A 听到**「房间3068已开好，把房间号告诉另一位玩家，说「加入房间3068」就能进来。等对手进来再开打。」
- **B 说**「加入房间3068」→ **B 听到**「你进了房间3068，对面是另一位玩家。对决开始，你先手，你14点生命值，他18点生命值。」
- **A 说**「战况如何」→ **A 听到**「第1轮，你生命值18/18、能量3；对手生命值14/14、能量3。等对手出招。」

### 第 1 轮

- **B 说**「公鸡」→ **B 听到**「你一记普攻已出手，等对手应对。」
  - 局面：B 14/14，能量 3→2；误识别被当成普攻并生效，锁定 3 点伤害。
- **A 说**「格挡」→ **A 听到**「对手一记普攻，暴击，你格挡，掉3点生命值，剩15，轮到你出招。」
  - 局面：A 18→15，能量 3→2；B 14/14，能量 2。
- **A 说**「强攻」→ **A 听到**「你一记强攻已出手，等对手应对。」
  - 局面：A 15/18，能量 2→0；锁定 5 点强攻，等 B 应对。
- **B 说**「承受」→ **B 听到**「刚才那一手。你一记普攻，暴击，对手格挡，掉3点生命值，剩15。对手一记强攻，你硬扛，掉5点，剩9，轮到你出招。」
  - 局面：B 14→9，能量 2→4；第 2 轮开始，轮到 B 出招。

### 第 2 轮

- **B 说**「大招」→ **B 听到**「你一记大招，暴击，对手能量耗尽只能硬扛，掉11点，剩4，等对手出招。」
  - 局面：A 15→4；B 9/14，能量 4→0，大招用掉；轮到 A 出招。
- **A 说**「强攻」→ **A 听到**「刚才那一手。你一记强攻，对手硬扛，掉5点，剩9。对手一记大招，暴击，你能量耗尽只能硬扛，掉11点，剩4。你一记强攻，暴击，对手能量耗尽只能硬扛，掉7点，剩2。第三轮开始，攻击伤害每轮加2，等对手出招。」
  - 局面：B 9→2；A 4/18，能量 0；第 3 轮开始，轮到 B 出招。

### 第 3 轮

- **B 说**「强攻」→ **B 听到**「刚才那一手。对手一记强攻，暴击，你能量耗尽只能硬扛，掉7点，剩2。你一记强攻，对手能量耗尽只能硬扛，掉7点，剩0。你击倒了对手，赢了这一局。」
  - 终局：B 2/14 胜，A 0/18 负；共 3 轮。

**复盘**：这一局两个玩家一半的生命值都是被「硬扛」吃掉的——能量不够时格挡闪避都用不出来。B 靠大招暴击（9+2=11）把 A 的生命值条一次性打穿，A 的反击只差 2 点就能翻盘。
