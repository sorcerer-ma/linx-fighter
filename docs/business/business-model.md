# 商业模式

> 状态：**设想与推演**，均未交付。本轮演示只包含「双人对战 + 伙伴播报」，养成、抽卡、周边与订阅都在讨论中，尚未进入实现。文中的同行数据与合规条款来自公开资料，来源链接随文标注，正式对外表述前需按最新规定复核。

产品侧定位见 [README](../../README.md#项目亮点)，规则与体验见[产品设计](../product/product-design.md)，同行案例详见[竞品调研](competitive-analysis.md)。

## 一句话

**我们卖的不是一局游戏，而是一只会长大的伙伴；对战是它每天被想起的理由。**

硬件已经有毛利，但硬件的天花板是出货量。真正决定价值的是：一台卖出去之后，用户第二年、第三年还在不在用、还愿不愿意为它再花一次钱。

## 商业价值（一页看完）

1. **市场不需要教育**。AI 陪伴玩具 2025 年上半年线上卖出约 160 万台、7.4 亿元，均价已落到 340 元上下；卡牌与潮玩分别做到百亿级营收。我们不需要发明一个新品类，只需要在既有付费习惯里拿到位置。
2. **我们站在两块成熟市场之间**。AI 玩具只会聊天，对战游戏要一块屏幕，实体卡牌没有声音——「面对面 + 两台设备 + 用嘴出招」这个组合目前没有人在做。
3. **增长不完全依赖买量**。一局对战天然带来一个新玩家：同桌效应是这个价位里成本最低的获客方式，也是周边与内容卖得出去的前提。

## 为什么这产品有机会收第二次钱

普通语音玩具的问题是「玩三天就腻」：内容是一次性的，答完就没了。我们的结构不一样：

1. **有一个可积累的角色资产**。伙伴有名字、性格、成长状态，随玩家一起变强。玩家不是换游戏，是换不掉自己的伙伴。
2. **有一场可以无限重玩的对抗**。七个动作、一种资源，每局走势不同；同样两个人可以打一年，不需要新的关卡。
3. **有一个天然的社交入口**。面对面发起挑战、四位编号进房，一场对战本身就是一次线下聚会。低龄用户的扩散靠同学，不靠广告。

## 三层收入结构

| 层 | 卖什么 | 付费点 | 为什么家长不反感 |
| --- | --- | --- | --- |
| 一 · 硬件 | 灵矽设备 + 内置伙伴 | 一次性硬件 | 已经是现有品类，不需要额外解释 |
| 二 · 内容 | 新精灵、新皮肤、新对战规则 | 单只精灵 / 皮肤 / 赛季内容 | 买的是「孩子能说得出名字的角色」，像买玩具不像充值 |
| 三 · IP | 精灵人设、卡牌、周边、线下赛事 | 盲盒/卡牌、联名、授权 | 看得见摸得着，能当礼物送 |

三层的关系：硬件负责进场，内容负责留存，IP 负责把「玩」变成「收集」。**收入重心要逐步从第一层挪到第二层和第三层**，否则永远只是一次性硬件生意。

定价上有个朴素的锚点：399 元这一档，家长不需要专门「决策」一次；59 元这一档，孩子花掉它通常不用跟家长报备。**价格带决定付费发生在谁手里**——这一点比定价本身更影响设计。

## 三个增长机制

### 1. 养成：把「走路」变成资源

随身设备能测步数，步数可以换「场外能量」：白天攒下的，晚上用来喂养、升级精灵。它与对局内的战斗能量是两套账——**场外能量只用于养成，不进战斗**。这条设计同时解决三件事——**给硬件一个每日开机理由**、**把线下活动换算成游戏收益**、**让「不打对战的日子」也有事可做**。

关键不是数值，而是结算时机：养成应当是「晚上回来看看它今天过得怎么样」，不是打卡领奖励。步数这类行为数据一旦能换稀缺物，就一定会被刷，所以**日封顶、只换养成不换战力**必须写在设计里，而不是等风控来兜。

### 2. 收集与克制：让精灵有属性，也有代价

不同精灵有不同的属性倾向（攻高防低、能量恢复快、闪避更强），进而在对局里形成相克关系。这带来两层收益：一是玩家会去尝试第二只、第三只精灵，收集动机自然出现；二是每只精灵都能长出一套人设，成为周边与卡牌的载体。

**所以真正被卖的是角色，不是设备能力。** 硬件是召唤器，一台设备可以住下多只精灵；付费理由就变成「我想要这一只」，而不是「我需要一个新功能」——这也是内容层和 IP 层能成立的前提。

**但克制关系必须克制**：数值差异只能制造「换一种打法」，不能制造「不买就打不过」。我们靠读招、蓄力和资源分配定胜负，这条底线一旦让给抽卡强度，产品就掉进家长最反感的那个坑里。

### 3. 同桌效应：让一局变成一圈

对战发生在同一空间，四位编号让「加入」这件事低于一次扫码的成本。这决定了我们的增长不是投放驱动，而是**班级/小区内的对战风潮**：一个孩子带着设备打赢了同学，下一个孩子会要求家长买一台。

因此产品要主动设计「围观」与「传话」：旁人能听见战况、能起哄、能被邀请补位。社交不是附加功能，是这个品类的获客方式。

反面同样要记住：**「两台设备才好玩」等于把获客成本乘以二**。拓麻歌子的联机价值是真的，但它的主机足够便宜、单机也能养。所以我们要做到「一台也能玩、两台才好玩」，否则家长的第一次反应是「为什么要买两个」。

## 从同行借来的做法

按可落地阶段排序，括号里是前提条件。

| 做法 | 借鉴自 | 阶段 | 为什么适合我们 |
| --- | --- | --- | --- |
| **认证道馆制**：展台/合作门店登记为对战点，打完一局盖一个电子戳，攒场次解锁出场特效 | 宝可梦卡牌道馆 | 近期，零硬件改动 | 服务端记场次 + 门店一张二维码即可，把「买过一次」变成「常来」 |
| **步数换能量，日封顶且只换养成** | 蚂蚁森林 | 近期，手机端计步即可 | 给硬件一个每日开机理由，同时不制造「多走路就能赢」 |
| **赛季积分只换称号与台词** | 羊了个羊、宝可梦积分赛 | 近期 | 语音对战天然产出「金句」，是最适合传播的素材 |
| **声音皮肤直购，不做随机抽取** | 泡泡玛特的定价锚点 + 抽卡合规要求 | 近期 | 卖精灵音色、口头禅、胜利台词，6–30 元，明码标价可试听；这是语音品类独有、且完全绕开抽卡合规的付费点 |
| **双人共同养育一只精灵** | Peridot 的繁育与 trait 继承 | 中期，需两台设备与监护人绑定 | 两人各养一半、步数汇入同一能量池，形态由两人的战绩共同决定；让内容由玩家生成，但把收益挂在「一起打」而不是「一起抽」 |
| **实体招式卡只做辅助，按套出售** | Amiibo 的轻解锁、Skylanders 的反例 | 中期，需二维码/NFC | 说出卡上招式或扫卡即召唤，给彩蛋不给胜负；一套买断比随机抽包更适合低龄场景 |
| **家长侧成长报告订阅，孩子端零付费** | 硬件 + 低价订阅的通行组合 | 中期 | 周报：说了多少句话、用了哪些策略词、胜率曲线、和谁玩；9.9 元/月。付费发生在家长手里，孩子界面里最好一个支付按钮都没有 |
| **校园赛事包**：规则卡、对阵表、奖状、赛季语音包 | 宝可梦赛事体系 | 长期，需先完成未成年人合规方案 | 把赛事做成可复制的运营物料，老师或店主能自己办起来 |

## 增长飞轮

```text
一台设备卖出去
  → 孩子每天和伙伴说话、养它（留存）
  → 带到学校/小区打一场，围观者想加入（裂变）
  → 新玩家要买自己的设备和自己的精灵（拉新）
  → 对战需要新打法，新精灵与赛季内容有市场（内容收入）
  → 角色有了自己的名字与故事，卡牌与周边成立（IP 收入）
  → 更多曝光与对战风潮（回到第一环）
```

飞轮里最容易断的是第一环到第二环：**设备买回来，孩子三天后就不玩了**。所以早期所有资源都该压在留存的头两周，而不是急着上付费点。

## 分阶段路线

| 阶段 | 目标 | 做什么 | 暂不做什么 |
| --- | --- | --- | --- |
| 现在（演示） | 证明双人语音对战好玩 | 面对面开房、语音泛化、伙伴播报与主动提醒 | 养成、付费、账号 |
| 半年内 | 证明「愿意每天打开」 | 步数与能量、精灵成长、第二只精灵、战绩与称号、家长侧只读报告（免费） | 抽卡、周边、赛事 |
| 一年内 | 证明「有人愿意为角色付钱」 | 精灵皮肤与声音包直购、新精灵内容包、认证道馆、线下小比赛、卡牌试水 | 大规模授权、跨 IP 联名 |
| 更长期 | 把角色做成 IP | 动画/漫画、周边、授权与合作赛事 | — |

每一阶段只回答一个问题，答不出来就不要进下一阶段——比同时上五个商业化功能更省钱。

## 需要盯的指标

- **次日与七日留存**：设备激活后是否每天被唤醒；这是飞轮第一环。
- **人均每周对局数**：对战是不是主玩法，而不是语音闲聊的附带。
- **邀请转化率**：一次对局之后，旁边有多少人真的买了设备。
- **伙伴对话占比**：多少时间在「不玩游戏」时也用它（养成与陪伴是否成立）。
- **内容复购率**：第二只精灵、第一套皮肤的购买比例。

## 边界（了解即可）

本轮是比赛作品展示，不收费、也不发行，下面几条只作为「将来真做成产品」时的边界记录，不影响现在的设计：

- 未成年人付费有硬限额，且若被认定为网络游戏，还要叠加实名、时段与版号，校园场景基本不可用；
- 随机抽取不能靠充值直接抽，须公示概率并提供直购途径；
- 儿童语音属敏感个人信息，须监护人同意、最小化留存。

值得注意的是，这些边界恰好印证了我们已经在走的路：**直购而不是抽卡、不做陌生人匹配、只传文字不存音频**。商业上真正要回答的问题不是如何过闸门，而是「这个位置值不值得被占」。

## 几条反直觉的判断

1. **低龄赛道的钱不是孩子付的，是家长付的；而一次退款纠纷的公关成本高于一年 ARPU。** 同品类里出现过未满 8 周岁儿童单笔充值数万元、退款在渠道之间互相推诿的公开纠纷（[报道](https://www.thepaper.cn/newsDetail_forward_27159008)）。所以付费设计要面向家长（硬件、订阅、礼盒），孩子的界面里最好一个支付按钮都没有。
2. **「抽卡 + IP」看起来最像我们的路，实际上最不该先做。** 泡泡玛特的高毛利背后是近 4,600 万会员、超九成会员贡献与近五成复购（[年报](https://prod-out-res.popmart.com/cms/ANNUAL_REPORT_2024_976e7e443e.pdf)），那是十年 IP 储备的结果；没有 IP 储备时，抽卡只留下合规风险。
3. **真正愿意长期付钱的人群，未必是中小学生。** 拓麻歌子这一轮复苏的主力是成年怀旧人群、海外销售过半（[万代](https://www.bandai.co.jp/press/2025/250828.php)）；AI 挂件类产品的用户里成年女性占多数（[报道](https://finance.sina.com.cn/wm/2026-07-13/doc-inihsuhu8827802.shtml)）。儿童向要背合规成本，成人向只背情怀——**产品可以是同一个，营销与付费必须分开**。
4. **硬件不是壁垒，玩法与 IP 才是。** 大模型能力已经被做成可采购的机芯方案，白牌化极快。我们能守住的只有两样：这套「语音 + 读招 + 面对面」的玩法规格，以及伙伴自己的名字与故事。

## 我们不做的事

- **不做付费变强**：卖角色、卖外观、卖故事，不卖胜率。
- **不做无限抽卡**：一次性内容包优先于纯随机抽取，家长能算清价格，孩子才不容易被「再来一次」套住。
- **不做陌生人匹配开局**：面对面对战既是体验，也是最有效的未成年人保护——对手是你认识的人。
- **不把伙伴做成客服**：它能提醒、能关心，但不做家电控制、不做学习辅导，边界清楚才不会变成四不像。
