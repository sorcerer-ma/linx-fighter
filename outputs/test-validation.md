# Linx Fighter 测试验证 v0.2

日期：2026-10-23。测试规则对应 [机制与数值设计](mechanics-and-balance.md)，本轮未调整参数。

## 测试口径

先手14血、后手18血；双方行动点初始3、上限5，各自首次主动行动不恢复，之后恢复2；蓄力+1；大招每局一次、花4点、伤害9、40%暴击额外+2、闪避成功率30%。普攻1点打3、强攻2点打5，暴击20%额外+2，闪避成功率50%；格挡1点减2。第3轮起双方攻击每轮累计增加2点。双方各主动行动一次为完整一轮。

8种进攻策略 × 8种对手策略 × 2种防守风格 × 每组合2,000局，共256,000局。随机种子20261023。增加了提前储点等待对方无点，以及按当轮大招伤害判断出手时机的策略。保留旧固定阈值策略供比较。次数耗尽后转普通进攻。

两种防守风格：优先最大化本次存活概率、其次最小化期望承伤；或者在行动点不高于2且承受本次暴击也不会倒下时主动承受，其余同前者。双方在一个测试组内采用相同防守风格，因此没有覆盖混合防守风格组合。

这些是启发式策略，不是最优策略求解，也不是硬件或人类测试。

## 结果

| 指标 | 结果 |
|---|---:|
| 平均结束轮数 | 4.30 |
| 在3～5轮结束 | 87.53% |
| 第3轮前结束 | 0.02% |
| 超过5轮 | 12.45% |
| 90/95分位结束轮数 | 均为6 |
| 策略池总体先手胜率 | 47.64% |

更愿意防守的一组，目标区间比例80.31%；更愿意承伤的一组94.76%。此前87.4%的结论在扩展策略池后基本稳定，但具体比例仍依赖策略池。

## 主要发现

1. 节奏目标大体达到，但并非所有策略组合都达到。双方持续普攻并优先防守时，只有61.9%在3～5轮结束，平均5.38轮。没有设置强制五轮截止；双方不进攻仍可拖延。
2. 总体接近五五开掩盖了局部先后手问题。双方按当前伤害判断大招时机，先手胜率约35.1%～35.3%；双方尽早大招约39.3%～43.0%。部分普攻镜像则为58.3%。不能宣称公平已验证。
3. 后期响应集中于闪避：在支付行动点进行响应的事件中，第4轮约78.5%选择闪避，第5轮约89.2%。这符合逐轮增伤、固定减伤的激励，但可能使后期决策单一。统计受当轮存活对局的构成影响，不是单一局面的因果对照。
4. 尽早大招在两种防守池中，面对其余策略的平均胜率均约61%；适应伤害的大招策略在承伤风格池约62%。普通强攻流明显较弱，但这不证明强攻这个动作本身无用。

## 判定与下一步

节奏：通过“多数对局3～5轮”的候选验证，硬截止目标未设定。
平衡：未通过全局公平验证，特定打法后手偏强。
语音场景：尚未验证，只能判断指令结构和流程具备可测试性。

建议冻结v0.2用于面对面试玩，观察生命补偿的接受度、状态理解、后期闪避集中以及大招失败体验。下一次数值对照应单独比较后手生命补偿，不同时改格挡与增伤。若后期选择单一在真人试玩中成立，再单独比较格挡随轮次变化的方案，避免直接堆叠规则。

## 复现与证据

在仓库根目录执行：

```sh
python3 tests/simulation/v02_validation.py
```

脚本使用 Python 标准库，读取同目录两个历史模拟模块的定义部分，不会运行它们的历史批量测试。约运行256,000局，更新 `tests/simulation/v02_validation_results.json`。固定随机种子为20261023；跨Python版本的随机序列与结果不承诺完全一致。

文件：`tests/simulation/v02_validation.py`、`tests/simulation/pace_tuning.py`、`tests/simulation/limited_ults.py`、`tests/simulation/v02_validation_results.json`。本次归档保留既有脚本结构，后续可重构，不能据此视为正式游戏实现。

## 面对面试玩计划

建议4对玩家，每对练习后进行4局，交替先后手。记录实际时长、轮数、指令重说、状态查询、大招时机及落空后的反应。该规模用于发现体验问题，不能证明公平。

重点询问玩家是否理解后手生命补偿、是否能看清点数和增伤、是否主动选择承受、以及后段是否只剩闪避。技术输入错误不计为战斗失败。真人试玩尚未执行。
